*【從設計圖到成品】*

## 類別、欄位與方法

類別（class）像設計圖，描述這一類物件應該有哪些資料、能做哪些事；物件（object）是照設計圖做出來的實體（instance）。「所見即物件」講的就是這個：只要有屬性（attribute）跟行為（behavior），就適合做成物件。

```java
class Pen {
    String brand;   // 欄位，也叫實體變數
    int price;

    void write() {  // 方法
        System.out.println(brand + " 正在書寫");
    }
}
```

欄位保存物件的狀態，方法描述它能做的事。**先設計類別，才產生物件。**

*【真的做出物件】*

## 宣告、實體化與初始化

```text
Pen myPen;            // 1. 宣告：準備一個裝得下 Pen 的變數
myPen = new Pen();    // 2. new 建立物件，3. = 把參考值放進變數

Pen yourPen = new Pen();   // 三步驟寫成一行
```

變數裡放的不是物件本身，而是**參考值**（object reference）——可以想成物件的取件號碼。每次 `new` 通常都會生出一個不同的物件；但如果寫 `Pen second = myPen;`，兩個變數就指向同一個物件，從任何一邊改，另一邊都看得到。

> 嚴格講，Java 虛擬機規格並沒有規定參考值一定就是原始記憶體位址，實作上可以是別的東西 [[出處]](https://docs.oracle.com/javase/specs/jvms/se21/html/jvms-2.html#jvms-2.7)。

沒有任何變數指得到的物件，就是垃圾回收器要收走的「垃圾」。Java 不讓你自己管那塊空間，全部交給 JVM。

*【變數住在哪個範圍】*

## 實體變數與區域變數

| 項目 | 實體變數 | 區域變數 |
|---|---|---|
| **宣告位置** | 類別內、方法外 | 方法或程式區塊內 |
| **屬於誰** | 每個物件各有一份 | 那一次方法執行 |
| **預設值** | 有 | 沒有，用之前一定要先給值 |
| **活多久** | 跟著物件 | 離開那個區塊就沒了 |

**預設值是在**建立物件**、配置那塊空間的時候才寫進去的，不是編譯時期。數值型欄位給 0（`double` 給 `0.0d`），`boolean` 給 `false`，參考型別給 `null`** [[出處]](https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.12.5)。

> 📝 原筆記更正：原筆記寫「Java會在編譯時給實體變數預設初始值」，查證後更正：預設值是建立物件、配置那塊空間的時候才寫進去的，不是編譯時期

`null` 表示「目前沒有指向任何物件」，只能給參考變數用。對 `null` 呼叫實體方法，就會拿到 `NullPointerException`。

*【面試常考這題】*

## Java 到底是傳值還是傳址

**Java 的參數傳遞一律是傳值。**基本型別複製的是資料值；參考型別複製的是**參考值**。所以方法拿到的是「同一個取件號碼的副本」——它可以改那個物件的內容，但沒辦法把呼叫端的變數換成另一個物件。

```java
static void changeNumber(int value) {
    value = 99;
}

static void changeFirst(int[] values) {
    values[0] = 99;      // 改的是同一個陣列物件
}

static void replaceArray(int[] values) {
    values = new int[]{7, 7};   // 只換掉副本指向誰，呼叫端不受影響
}

int number = 10;
int[] scores = {10, 20};

changeNumber(number);   // number 還是 10
changeFirst(scores);    // scores[0] 變成 99
replaceArray(scores);   // scores 還是原來那個陣列
```

**Java 只有傳值一種機制。說「物件是傳址」會讓人以為方法能替換呼叫端的變數，實際上不行——被複製的是參考值，不是物件** [[出處]](https://docs.oracle.com/javase/specs/jls/se21/html/jls-8.html#jls-8.4.1)。

> 📝 原筆記更正：原筆記在 Udemy Chapter 1~3 的範例註解寫「Java => copy by reference」，模組11 則寫「傳址：Address Copy」且註明「在定義上一直有所爭議」，查證後更正：Java 只有傳值一種，參考型別傳的是參考值的副本

*【建立時就準備好】*

## 建構子與 this

建構子（constructor）在建立物件時負責初始化。兩條規定：**名稱必須跟類別一樣**，而且**不能宣告回傳型別**——連 `void` 都不能寫，寫了就變成一般方法。

```java
class Circle {
    private double radius;

    Circle() {
        this(1.0);            // 呼叫同類別的另一個建構子
    }

    Circle(double radius) {
        this.radius = radius; // this.radius 是欄位，radius 是參數
    }
}
```

`this` 代表「目前這個物件」。`this(...)` 可以呼叫同類別的另一個建構子；長年以來它必須放在第一行，所以跟 `super(...)`（〈封裝、繼承、多型〉會講）只能擇一。Java 25 起這條放寬了：`super(...)` 與 `this(...)` 前面可以先寫敘述（例如先驗證參數），只是那段前置程式不能讀取正在建立中的物件（不能用 `this`、不能讀欄位、不能呼叫實體方法），但可以指定它自己的欄位 [[出處]](https://openjdk.org/jeps/513)。「兩者擇一」這點沒變。

如果一個類別完全沒寫建構子，編譯器會補一個無參數的；一旦你自己宣告了任何建構子，那個免費的就不會出現了。

> Java 16 起，只是要裝幾個值的資料類別可以直接用 `record`：`record Point(int x, int y) {}` 一行就自動有建構子、存取方法、`equals`、`hashCode` 與 `toString`。

*【固定長度的一排格子】*

## 陣列與多維陣列

陣列（array）裝固定數量、同一型別的元素。**陣列本身是物件**，索引從 0 開始，最後一格是 `length - 1`。長度在 `new` 的當下就定了，之後不能改。

```java
int[] scores = {80, 90, 70};
System.out.println(scores[0]);      // 80
System.out.println(scores.length);  // 3，沒有小括號

int[][] seats = {
    {1, 2, 3},
    {4, 5}          // 每一列長度可以不同
};
```

`length` 是陣列的屬性，後面不加小括號；`String` 的 `length()` 才是方法，這兩個很容易打混。Java 的多維陣列其實是「陣列裡放陣列」，所以每一列長度可以不一樣。

把一個陣列變數指定給另一個變數，只是複製參考值，兩邊還是同一個陣列。要真正的獨立副本得用 `Arrays.copyOf`。

```java
int[] iArray3 = {100, 200, 300, 50};
Arrays.sort(iArray3);                            // {50, 100, 200, 300}
System.out.println(Arrays.binarySearch(iArray3, 50));   // 0
System.out.println(Arrays.binarySearch(iArray3, 150));  // -3
```

> 用 `Arrays.binarySearch` 之前一定要先排序。找不到時回傳的是負數：150 應該插在索引 2 的位置，回傳值是 `-(2) - 1 = -3`。只要結果小於 0 就代表沒找到。

*【看似文字，其實也是物件】*

## String 的不可變與比較

`String` 是參考型別，而且**不可變（immutable）**：看起來在改字串的方法，其實都是回傳一個新字串，原來那個動都沒動。

```java
String name = "Java";
String upper = name.toUpperCase();

System.out.println(name);   // Java   ← 沒被改到
System.out.println(upper);  // JAVA
```

`==` 對參考型別比的是「是不是同一個物件」，跟內容無關，所以判斷字串內容要用 `equals()`。直接寫成字面值的字串會放進字串池（String Pool）重複使用，所以 `"Hi" == "Hi"` 會是 `true`——那是字串池的效果，不是 `==` 在比內容；但用 `new` 做出來的就是兩個不同物件：

```java
String left  = new String("Hi");
String right = new String("Hi");

System.out.println(left == right);       // false，兩個不同物件
System.out.println(left.equals(right));  // true，內容一樣
```

常用方法：`length()`、`charAt(index)`、`substring(begin, end)`（**結束索引那個字元不取**）、`isEmpty()`、`indexOf()`、`compareTo()`。

> 要在迴圈裡大量串接字串時，改用 `StringBuilder` 比較省——這一組的取捨（String、StringBuffer、StringBuilder）在〈Java 基礎快答〉有速查版。

**直接印一個沒有覆寫 `toString()` 的物件（例如陣列），會看到像 `[Ljava.lang.String;@776ec8df` 這樣的東西。`@` 後面那串是識別雜湊碼（identity hash code），不保證等於記憶體位址** [[出處]](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Object.html#toString())。要看陣列內容請用 `Arrays.toString(陣列)`。

*【整個類別共同擁有】*

## static 成員

一般欄位屬於個別物件，`static` 成員屬於**類別本身**，該類別生出來的所有物件共用同一份。存取時建議寫類別名稱，讀的人一眼就知道它不是某個物件私有的。

```java
class Counter {
    static int total;   // 所有物件共用
    int personal;       // 每個物件各一份

    Counter() {
        total++;
        personal++;
    }
}

System.out.println(Counter.total);
```

類別第一次被 JVM 載入時，static 的東西就先就位了——那時候**一個物件都還沒建立**。所以：

- 不必建立物件就能用 static 成員（`Math.max()` 這個方法、`Math.PI` 這個常數都是這樣用的）。
- static 方法裡不能用 `this`，因為沒有「目前這個物件」。
- static 方法不能直接存取實體欄位或實體方法，反過來則可以。

> 💡 **常數最適合搭 static：`public static final double PI = 3.14;`**

*【不固定數目的輸入】*

## 可變引數 varargs

可變引數（varargs）讓呼叫端傳 0 到多個同型別的值，方法內部當成陣列用。

```java
static int sum(int... numbers) {
    int total = 0;
    for (int number : numbers) {
        total += number;
    }
    return total;
}

sum();            // 0
sum(1, 2, 3);     // 6
```

兩條規定：一個方法最多只能有一個可變引數，而且必須放在參數列**最後面**。

### 重點整理

- 類別是規格，物件是照規格做出來的實體；變數裡放的是參考值不是物件。
- Java 一律傳值——傳物件時複製的是參考值，所以改得動內容、換不掉變數。
- 建構子跟類別同名而且沒有回傳型別；自己寫了建構子，免費的無參數版本就消失。
- 陣列長度固定、索引從 0 起，`length` 不加小括號；字串比內容用 `equals`。
- 實體變數有預設值（建立物件時給），區域變數沒有，用之前一定要先給值。
- `static` 成員屬於類別、大家共用，裡面不能用 `this`。

- (A) 只有陣列採用傳值
- (B) 基本型別傳值，物件一律傳址
- (C) 所有參數都會複製整個物件
- (D) 一律傳值；傳物件時複製的是參考值的副本

<details><summary>看答案</summary>

**答案：(D)** Java 沒有傳址機制。方法拿到參考值的副本，所以改得動物件內容，但換不掉呼叫端的變數。

</details>

**Q2. Pen second = first; 在 first 已經指向某個 Pen 物件時，代表什麼？**

- (A) 把 first 指向的物件清掉
- (B) second 與 first 指向同一個物件
- (C) 把 Pen 轉成基本型別
- (D) 自動複製出一個內容相同的新物件

<details><summary>看答案</summary>

**答案：(B)** 指定參考變數只複製參考值，不會幫你複製整個物件。

</details>

**Q3. 實體變數的預設值是什麼時候寫進去的？**

- (A) 第一次讀取它的時候
- (B) 垃圾回收器執行的時候
- (C) 建立物件、配置那塊空間的時候

<details><summary>看答案</summary>

**答案：(C)** 預設值在物件建立時就位；編譯期不做這件事，區域變數則根本沒有預設值。
