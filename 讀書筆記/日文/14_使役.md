# 14. 使役

> 來源：[筆記平台 · 日文](https://hhtim.github.io/notes-platform/japanese/#/lesson/n4-causative)　第 14 課 / 共 18 課 · 約 38 分鐘

**使役形三類變法（書かせる、買わせる、帰らせる、食べさせる、させる、来させる），使役形照第二類變（行かせない、行かせて），「叫」（對方不一定想做）與「讓」（對方想做、我答應）看上下文分，做的人用 に 還是 を（句子已有 を 一般用 に；を／に 不分叫或讓），以及 〜させてください（請讓我～，跟 〜てください 比）、〜させてもらえませんか、〜させていただけませんか；45 題課中練習。**

### 讀完這課你會

*   把三類動詞變成使役形
*   分清楚使役形的「叫」和「讓」
*   知道被叫的人什麼時候用 に
*   用 〜させてください 說「請讓我～」
*   用 〜させていただけませんか 客氣地請對方讓我做

*【「叫人做」「讓人做」的動詞樣子】*

## 使役形是什麼；第一類怎麼變

動詞變成「叫人做～、讓人做～」意思的樣子叫**使役形**：飲（の）む（喝）→飲（の）ませる（叫人喝、讓人喝）。[出處](https://kotobank.jp/word/%E4%BD%BF%E5%BD%B9-516592) 第一類的使役形，從ない形看最快：

*   **去掉 ない，加 せる**：書（か）かない→書（か）かせる。也就是辭書形最後一個音從 う段 換成 あ段，再加 せる。[出處](https://kotobank.jp/word/%E3%81%9B%E3%82%8B-549042)
*   **う 結尾變 わ**：跟ない形一樣，買（か）う→買（か）わない→買（か）わせる，不是 あせる。
*   **長得像第二類的第一類**：帰（かえ）る、入（はい）る、走（はし）る 是第一類：帰（かえ）らせる、入（はい）らせる、走（はし）らせる。
*   **行（い）く 照規則**：行（い）かない→行（い）かせる。

> 第一類：ない形去掉 ない＋せる（書（か）か＋せる→書（か）かせる）

| 辭書形 | ない形 | 使役形 |
| --- | --- | --- |
| 買（か）う | 買（か）わない | 買（か）わせる |
| 書（か）く | 書（か）かない | 書（か）かせる |
| 急（いそ）ぐ | 急（いそ）がない | 急（いそ）がせる |
| 話（はな）す | 話（はな）さない | 話（はな）させる |
| 待（ま）つ | 待（ま）たない | 待（ま）たせる |
| 遊（あそ）ぶ | 遊（あそ）ばない | 遊（あそ）ばせる |
| 飲（の）む | 飲（の）まない | 飲（の）ませる |
| 作（つく）る | 作（つく）らない | 作（つく）らせる |
| 帰（かえ）る | 帰（かえ）らない | 帰（かえ）らせる |
| 行（い）く | 行（い）かない | 行（い）かせる |

*【第二類加 させる，第三類要記】*

## 第二類、第三類的使役形與變化

*   **第二類**：去掉 る，加 させる：食（た）べる→食（た）べさせる。從ない形看也一樣：食（た）べない 去掉 ない，加 させる。[出處](https://kotobank.jp/word/%E3%81%95%E3%81%9B%E3%82%8B-510767)
*   **する**：使役形是 させる。名詞加 する 的動詞也一樣：勉強（べんきょう）する→勉強（べんきょう）させる。[出處](https://kotobank.jp/word/%E3%81%9B%E3%82%8B-549042)
*   **来（く）る**：使役形是 来（こ）させる（讀 こさせる），開頭的 こ 跟ない形 来（こ）ない 一樣。[出處](https://kotobank.jp/word/%E3%81%95%E3%81%9B%E3%82%8B-510767)

| 辭書形 | 使役形 | 類 |
| --- | --- | --- |
| 食（た）べる | 食（た）べさせる | 第二類 |
| 覚（おぼ）える | 覚（おぼ）えさせる | 第二類 |
| 調（しら）べる | 調（しら）べさせる | 第二類 |
| 考（かんが）える | 考（かんが）えさせる | 第二類 |
| する | させる | 第三類 |
| 来（く）る | 来（こ）させる | 第三類 |

使役形本身照第二類動詞變：る 換成 ます、ない、た、て。[出處](https://kotobank.jp/word/%E3%81%9B%E3%82%8B-549042) [出處](https://kotobank.jp/word/%E3%81%95%E3%81%9B%E3%82%8B-510767)

| 使役形 | ます形 | ない形 | た形 | て形 |
| --- | --- | --- | --- | --- |
| 行（い）かせる | 行（い）かせます | 行（い）かせない | 行（い）かせた | 行（い）かせて |
| 食（た）べさせる | 食（た）べさせます | 食（た）べさせない | 食（た）べさせた | 食（た）べさせて |
| させる | させます | させない | させた | させて |

*【同一個形狀，兩種意思】*

## 「叫」與「讓」

使役形的句子，主詞是要別人做事的人，做動作的人用 に（有時用 を）標：[出處](https://www.jstage.jst.go.jp/article/gengo/148/0/148_143/_pdf)

> 要別人做的人＋は（が）＋做的人＋に／を＋使役形

同一個使役形，有兩種意思，看上下文分：[出處](https://kotobank.jp/word/%E3%81%95%E3%81%9B%E3%82%8B-510767) [出處](https://kotobank.jp/word/%E3%81%9B%E3%82%8B-549042)

*   **叫（要求、命令）**：對方不一定想做，主詞要他去做。母（はは）は弟（おとうと）に野菜（やさい）を食（た）べさせました。（媽媽叫弟弟吃青菜。）
*   **讓（允許、隨他去做）**：對方想做，主詞答應或不阻止。父（ちち）は私（わたし）を日本（にほん）に留学（りゅうがく）させてくれました。（爸爸讓我去日本留學。）

*   部長（ぶちょう）は新人（しんじん）に会議（かいぎ）の資料（しりょう）をコピーさせました。  
    部長叫新人影印會議資料。
*   先生（せんせい）は学生（がくせい）に毎週（まいしゅう）作文（さくぶん）を書（か）かせます。  
    老師每週叫學生寫作文。
*   弟（おとうと）は野菜（やさい）が嫌（きら）いです。でも、母（はは）は毎日（まいにち）食（た）べさせます。  
    弟弟討厭青菜。可是媽媽每天都叫他吃。
*   息子（むすこ）はサッカーが大好（だいす）きです。だから、毎週末（まいしゅうまつ）サッカーをさせています。  
    兒子很喜歡足球。所以每個週末都讓他踢足球。
*   子供（こども）たちを公園（こうえん）で自由（じゆう）に遊（あそ）ばせました。  
    讓孩子們在公園自由地玩。（自由（じゆう）に：自由地）

*【做的人後面接什麼】*

## 做的人用 に 還是 を

*   **句子裡已經有 を**：動作有對象（野菜（やさい）を食（た）べる、資料（しりょう）をコピーする），這種句子，做的人一般用 に：子供（こども）に薬（くすり）を飲（の）ませる。
*   **動詞本身不帶 を**：行（い）く、帰（かえ）る、来（く）る 這種動詞，做的人用 を 或 に 都說得到：学生（がくせい）を帰（かえ）らせる、学生（がくせい）に帰（かえ）らせる。[出處](https://www.jstage.jst.go.jp/article/gengo/148/0/148_143/_pdf)
*   **を／に 不是用來分「叫」和「讓」**：兩種意思都要看上下文。[出處](https://www.jstage.jst.go.jp/article/gengo/148/0/148_143/_pdf)

*   母（はは）は子供（こども）に薬（くすり）を飲（の）ませました。  
    媽媽餵孩子吃了藥。（日文的藥用「喝」）
*   店長（てんちょう）はアルバイトの学生（がくせい）にレジの使（つか）い方（かた）を覚（おぼ）えさせました。  
    店長叫打工的學生記住收銀機的用法。（使（つか）い方（かた）：用法）
*   子供（こども）は早（はや）く帰（かえ）りたかったです。だから、子供（こども）を先（さき）に帰（かえ）らせました。  
    孩子想早點回家，所以讓他先回去了。（先（さき）に：先）
*   子供（こども）を一人（ひとり）で買（か）い物（もの）に行（い）かせました。  
    讓孩子一個人去買東西。

*【請對方讓我做】*

## 〜させてください、〜させていただけませんか

使役形的て形加 ください，是「請讓我～」：請對方答應讓我做。這課先學做的人是我的用法。[出處](https://kotobank.jp/word/%E3%81%95%E3%81%9B%E3%82%8B-510767)

> 使役形的て形＋ください（払（はら）う→払（はら）わせる→払（はら）わせてください）

*   **跟 〜てください 不一樣**：写真（しゃしん）を撮（と）ってください 是請對方拍；写真（しゃしん）を撮（と）らせてください 是請對方讓我拍。
*   **〜させてもらえませんか**：比 〜させてください 客氣，跟〈授受〉的 〜てもらえませんか 同一個接法。[出處](https://kotobank.jp/word/%E3%81%95%E3%81%9B%E3%82%8B-510767) [出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L09.pdf)
*   **〜させていただけませんか**：再更客氣，可以對客戶、上司用。いただく 是 もらう 的客氣說法，在〈敬語入門〉；這課先整句記。[出處](https://www.bunka.go.jp/seisaku/bunkashingikai/sokai/sokai_6/pdf/keigo_tousin.pdf)
*   **什麼時候用 〜させていただく**：基本上是自己要做的事，得到對方允許、自己也因此受惠的時候。[出處](https://www.bunka.go.jp/seisaku/bunkashingikai/sokai/sokai_6/pdf/keigo_tousin.pdf)

*   今日（きょう）は私（わたし）に払（はら）わせてください。  
    今天讓我付錢吧。
*   すみません、少（すこ）し考（かんが）えさせてください。  
    不好意思，請讓我考慮一下。
*   その仕事（しごと）は私（わたし）にやらせてください。  
    那份工作請讓我來做。（やる：做，比 する 口語）
*   すみません、ここで写真（しゃしん）を撮（と）らせてもらえませんか。  
    不好意思，可以讓我在這裡拍照嗎？
*   この会議室（かいぎしつ）を少（すこ）し使（つか）わせていただけませんか。  
    可以讓我用一下這間會議室嗎？（很客氣）

「被逼著做～」的 〜させられる（使役加被動）之後的課再學。

### 重點整理

*   第一類：ない形去 ない＋せる（書（か）かせる、買（か）わせる、帰（かえ）らせる、行（い）かせる）。
*   第二類：去 る＋させる（食（た）べさせる）。第三類：する→させる，来（く）る→来（こ）させる（こさせる）。
*   使役形照第二類變：行（い）かせます、行（い）かせない、行（い）かせた、行（い）かせて。
*   兩種意思看上下文：叫（對方不一定想做）、讓（對方想做，我答應）。
*   主詞是要別人做的人；做動作的人用 に（有時用 を）標。
*   句子裡已經有 を，做的人一般用 に；行（い）く、帰（かえ）る 這種不帶 を 的動詞，を、に 都說得到；を／に 不分叫或讓。
*   〜させてください：請讓我～（這課先學做的人是我的用法）；〜てください：請你～。
*   客氣程度：〜させてください → 〜させてもらえませんか → 〜させていただけませんか。

**Q4. 母（はは）は父（ちち）に毎日（まいにち）運動（うんどう）（　　）。（媽媽要爸爸每天運動。）**

**Q8. 想對客戶說「可以讓我參觀貴公司的工廠嗎？」，哪一句最適合？**
