# 16. 樣子與傳聞

> 來源：[筆記平台 · 日文](https://hhtim.github.io/notes-platform/japanese/#/lesson/n4-sou)　第 16 課 / 共 18 課 · 約 40 分鐘

**そうだ 的兩種意思：樣態「看起來」（ます形去 ます、い形容詞去 い、な形容詞直接接：降りそう、おいしそう、元気そう，いい→よさそう、ない→なさそう，そうな＋名詞、そうに＋動詞，〜そうもありません）與傳聞「聽說」（普通形＋そうだ：降るそう、おいしいそう、元気だそう，〜によると），以及怎麼從接法分辨兩者；50 題課中練習。**

### 讀完這課你會

*   用 〜そうだ 說「看起來～」
*   用動詞＋そうだ 說「快要～、看樣子會～」
*   用 そうな＋名詞、そうに＋動詞
*   記住 よさそう、なさそう 兩個特別的變法
*   用普通形＋そうだ 說「聽說～」
*   用 〜によると 說消息從哪裡來
*   從接法分出是「看起來」還是「聽說」

*【同一個 そうだ，兩種意思】*

## 看起來的 そうだ 與聽說的 そうだ

句尾的 そうだ（敬體是 そうです）有兩種：

*   **樣態**（看起來的樣子）：看了東西或情況，說「看起來～」「看樣子會～」。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf) [出處](https://kotobank.jp/word/%E3%81%9D%E3%81%86%E3%81%A0-552810)
*   **傳聞**（聽別人說的）：把聽來或讀到的消息告訴別人，說「聽說～」。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf) [出處](https://kotobank.jp/word/%E3%81%9D%E3%81%86%E3%81%A0-552810)
*   **兩種的接法不同**：看 そう 前面接的是什麼樣子，就分得出是哪一種。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf)

|   | 樣態（看起來） | 傳聞（聽說） |
| --- | --- | --- |
| 動詞 | 遅（おく）れそうです | 遅（おく）れるそうです |
| い形容詞 | おいしそうです | おいしいそうです |
| な形容詞 | 暇（ひま）そうです | 暇（ひま）だそうです |
| 名詞 | （不用） | 雨（あめ）だそうです |

*   **樣態**：動詞用 ます形去 ます，い形容詞拿掉 い，な形容詞直接接。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **傳聞**：前面是普通形（〈普通形與連接句子〉學的樣子）。[出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L18.pdf)

*   電車（でんしゃ）が遅（おく）れそうです。  
    （外面雪下得很大）電車看起來會誤點。
*   電車（でんしゃ）が遅（おく）れるそうです。  
    （聽了車站廣播）聽說電車會誤點。
*   このかき氷（ごおり）、おいしそうですね。  
    （刨冰剛端上桌）這碗刨冰看起來很好吃耶。
*   駅前（えきまえ）のかき氷（ごおり）屋（や）は、おいしいそうです。  
    聽說車站前那家刨冰店很好吃。

*【看了樣子說】*

## 形容詞＋そうだ（看起來～）

看到東西或人的樣子，覺得「應該是這樣」時，用 そうだ。這時候還沒有確認過：看到蛋糕說 おいしそう，是還沒吃。[出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L12.pdf) [出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)

> い形容詞去 い＋そうだ／な形容詞＋そうだ

| 形容詞 | 看起來～ | 意思 |
| --- | --- | --- |
| 重（おも）い | 重（おも）そうだ | 看起來很重 |
| 辛（から）い | 辛（から）そうだ | 看起來很辣 |
| 難（むずか）しい | 難（むずか）しそうだ | 看起來很難 |
| 元気（げんき） | 元気（げんき）そうだ | 看起來很有精神 |
| 暇（ひま） | 暇（ひま）そうだ | 看起來很閒 |
| いい | よさそうだ | 看起來不錯 |
| ない | なさそうだ | 看起來沒有 |

*   **い形容詞拿掉 い**：✗ おいしいそう → ✓ おいしそう。おいしいそう 是另一個意思（聽說好吃），後面會學。[出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L12.pdf) [出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf)
*   **な形容詞直接接**：不加 な、だ：✗ 元気（げんき）なそう → ✓ 元気（げんき）そう。[出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L12.pdf)
*   **いい 變成 よさそう**：✗ いいそう（想說「看起來不錯」時）→ ✓ よさそう。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf) [出處](https://kotobank.jp/word/%E3%81%9D%E3%81%86%E3%81%A0-552810)
*   **「沒有」的 ない 變成 なさそう**：時間（じかん）がなさそう（看起來沒有時間）。[出處](https://kotobank.jp/word/%E3%81%9D%E3%81%86%E3%81%A0-552810)
*   **否定**：い形容詞用 〜くなさそう：高（たか）くなさそう（看起來不貴）。な形容詞用 〜じゃなさそう：暇（ひま）じゃなさそう（看起來不閒）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **名詞不接這個 そう**：✗ 学生（がくせい）そうです。否定的 学生（がくせい）じゃなさそうです（看起來不像學生）可以說。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **一看就知道的事不用**：眼前的花很漂亮，直接說 きれいですね，不說 ✗ きれいそうですね；個子高、可愛也一樣。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)

*   この牛肉麺（ぎゅうにくめん）、辛（から）そうですね。  
    （看著菜單上的照片）這碗牛肉麵看起來很辣耶。
*   そのスーツケース、重（おも）そうですね。手伝（てつだ）いましょうか。  
    那個行李箱看起來很重耶。我來幫忙吧？
*   部長（ぶちょう）は今日（きょう）、機嫌（きげん）がよさそうです。  
    經理今天看起來心情不錯。
*   王（おう）さんは忙（いそが）しくて、時間（じかん）がなさそうです。  
    王先生很忙，看起來沒有時間。
*   このレストランは、あまり高（たか）くなさそうです。  
    這家餐廳看起來不太貴。
*   うわ、この問題（もんだい）、難（むずか）しそう。  
    （翻開考卷）哇，這題看起來好難。

*【快要～、看樣子會～】*

## 動詞＋そうだ

動詞接 そうだ，說的是「看樣子快要發生」，或是「照現在的情況，看起來會～」。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf) [出處](https://kotobank.jp/word/%E3%81%9D%E3%81%86%E3%81%A0-552810)

> ます形去 ます＋そうだ

| 辭書形 | ます形 | 看起來會～ |
| --- | --- | --- |
| 降（ふ）る | 降（ふ）ります | 降（ふ）りそうだ |
| 泣（な）く | 泣（な）きます | 泣（な）きそうだ |
| 終（お）わる | 終（お）わります | 終（お）わりそうだ |
| 切（き）れる | 切（き）れます | 切（き）れそうだ |
| 晴（は）れる | 晴（は）れます | 晴（は）れそうだ |
| 来（く）る | 来（き）ます | 来（き）そうだ |

*   **快要發生**：眼看就要發生的事。常跟 今（いま）にも（眼看就要）一起用：今（いま）にも泣（な）きそうです（眼看就要哭了）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf) [出處](https://kotobank.jp/word/%E3%81%9D%E3%81%86%E3%81%A0-552810)
*   **看樣子會～**：照現在看到的情況，預想之後會這樣：午後（ごご）は晴（は）れそうです（下午看起來會放晴）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **辭書形＋そう 是聽說**：✗ 降（ふ）るそう（想說「看起來會下」時）→ ✓ 降（ふ）りそう。降（ふ）るそうです 是「聽說會下」。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **来（く）る、する**：ます形是 来（き）ます、します，所以是 来（き）そう（讀 きそう）、しそう。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **否定**：動詞說「看樣子不會～」用 〜そうもありません（常體 〜そうもない）：終（お）わりそうもありません（看樣子做不完）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)

*   スマホの電池（でんち）が切（き）れそうです。  
    手機看起來快沒電了。
*   迷子（まいご）の子供（こども）が、今（いま）にも泣（な）きそうです。  
    走失的孩子眼看就要哭了。
*   雲（くも）がなくなりましたね。午後（ごご）は晴（は）れそうです。  
    雲散了耶。下午看起來會放晴。
*   人気（にんき）のパンが売（う）り切（き）れそうです。急（いそ）ぎましょう。  
    受歡迎的麵包看起來快賣完了。我們快一點吧。
*   今日（きょう）は仕事（しごと）が早（はや）く終（お）わりそうです。  
    今天工作看起來會早點結束。
*   この資料（しりょう）、今日中（きょうじゅう）には終（お）わりそうもありません。  
    這份資料看樣子今天之內做不完。

## そうな＋名詞、そうに＋動詞

そう 後面接名詞時用 そうな，接動詞時用 そうに，變法跟 な形容詞一樣（静（しず）かな町（まち））。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf) [出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L12.pdf)

> 〜そうな＋名詞／〜そうに＋動詞

*   **そうな＋名詞**：おいしそうなパン（看起來很好吃的麵包）、よさそうな店（みせ）（看起來不錯的店）、泣（な）きそうな顔（かお）（快哭出來的表情）。[出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L12.pdf)
*   **そうに＋動詞**：說做那個動作時的樣子：楽（たの）しそうに話（はな）す（聊得很開心的樣子）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **不用 の**：✗ おいしそうのパン → ✓ おいしそうなパン。

*   夜市（よいち）で、おいしそうな屋台（やたい）を見（み）つけました。  
    在夜市找到一攤看起來很好吃的攤子。
*   駅（えき）の近（ちか）くに、よさそうなホテルがあります。  
    車站附近有一家看起來不錯的飯店。
*   陳（ちん）さんは、泣（な）きそうな顔（かお）で電話（でんわ）をかけていました。  
    陳先生一臉快哭出來的樣子在打電話。
*   子供（こども）たちが公園（こうえん）で楽（たの）しそうに遊（あそ）んでいます。  
    孩子們在公園玩得很開心的樣子。

    林先生一副很好喝的樣子在喝啤酒。

*【聽別人說的】*

## 普通形＋そうだ（聽說～）

把聽來或讀到的消息轉告別人時，句尾用普通形＋そうだ（敬體 そうです）：「聽說～」。[出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L18.pdf) [出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf)

> 普通形＋そうだ（名詞、な形容詞的現在：〜だそうだ）

|   | 現在 | 否定 | 過去 |
| --- | --- | --- | --- |
| 動詞 | 来（く）るそうです | 来（こ）ないそうです | 来（き）たそうです |
| い形容詞 | 高（たか）いそうです | 高（たか）くないそうです | 高（たか）かったそうです |
| な形容詞 | 有名（ゆうめい）だそうです | 有名（ゆうめい）じゃないそうです | 有名（ゆうめい）だったそうです |
| 名詞 | 休（やす）みだそうです | 休（やす）みじゃないそうです | 休（やす）みだったそうです |

*   **名詞、な形容詞要加 だ**：✗ 雨（あめ）そうです → ✓ 雨（あめ）だそうです。這點跟〈推測〉的 でしょう、かもしれない 拿掉 だ 不同。[出處](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L18.pdf)
*   **過去、否定放在前面**：そうです 本身不變成過去、否定：✗ 来（く）るそうでした → ✓ 来（き）たそうです；✗ 来（く）るそうじゃありません → ✓ 来（こ）ないそうです。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf)
*   **消息從哪裡來**：用 〜によると（根據～）或 〜の話（はなし）では（照～的說法）放在句子前面：天気予報（てんきよほう）によると（根據氣象預報）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf)
*   **其他說法**：表示「聽說」「好像」的還有 〜らしい、〜ようだ，到 N3 再學。

*   天気予報（てんきよほう）によると、週末（しゅうまつ）は台風（たいふう）が来（く）るそうです。  
    氣象預報說，週末颱風會來。
*   王（おう）さんのお兄（にい）さんは、エンジニアだそうです。  
    聽說王先生的哥哥是工程師。
*   駅前（えきまえ）の新（あたら）しいラーメン屋（や）は、すごくおいしいそうです。  
    聽說車站前新開的拉麵店非常好吃。
*   陳（ちん）さんの話（はなし）では、あの映画（えいが）はあまりおもしろくないそうです。  
    照陳先生的說法，那部電影不太好看。
*   林（りん）さんは昨日（きのう）、会社（かいしゃ）を休（やす）んだそうです。  
    聽說林先生昨天向公司請假了。
*   田中（たなか）さんは来週（らいしゅう）、大阪（おおさか）に引（ひ）っ越（こ）すそうです。  
    聽說田中先生下星期要搬去大阪。

*【看接法就分得出來】*

## 兩個 そうだ 怎麼分

*   **前面是辭書形、た形、ない形這些普通形**：聽說。降（ふ）るそうです（聽說會下）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf)
*   **前面是 ます形去 ます**：看起來。降（ふ）りそうです（看起來會下）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei18_1.pdf)
*   **い形容詞**：留著 い 是聽說（甘（あま）いそうです），拿掉 い 是看起來（甘（あま）そうです）。[出處](https://www.jpf.go.jp/j/urawa/j_rsorcs/textbook/setsumei_pdf/setsumei19_4.pdf)
*   **な形容詞**：有 だ 是聽說（丈夫（じょうぶ）だそうです），沒有 だ 是看起來（丈夫（じょうぶ）そうです）。
*   **名詞**：只有聽說的 〜だそうです。
*   **いい**：いいそうです 是聽說，よさそうです 是看起來。

|   | 樣態（看起來） | 傳聞（聽說） |
| --- | --- | --- |
| 動詞 | 降（ふ）りそうです | 降（ふ）るそうです |
| い形容詞 | 甘（あま）そうです | 甘（あま）いそうです |
| な形容詞 | 丈夫（じょうぶ）そうです | 丈夫（じょうぶ）だそうです |
| 名詞 | （不用） | 台湾人（たいわんじん）だそうです |
| いい | よさそうです | いいそうです |
| ない | なさそうです | ないそうです |

*   この傘（かさ）は丈夫（じょうぶ）そうです。  
    （在店裡拿起來看）這把傘看起來很耐用。
*   この傘（かさ）は丈夫（じょうぶ）だそうです。  
    （看了網路評價）聽說這把傘很耐用。
*   このケーキは甘（あま）そうです。  
    這個蛋糕看起來很甜。
*   このケーキは甘（あま）いそうです。  
    聽說這個蛋糕很甜。

- (C) 聽說這個蛋糕很甜

<details><summary>看答案</summary>

**答案：(C)** 整句：聽說這個蛋糕很甜。  
甘（あま）い 留著 い 接 そうです，是普通形，所以是「聽說」。「看起來很甜」是 甘（あま）そうです。

### 重點整理

*   樣態（看起來）：ます形去 ます、い形容詞去 い、な形容詞直接接 そうだ：降（ふ）りそう、おいしそう、元気（げんき）そう。
*   いい→よさそう，「沒有」的 ない→なさそう；名詞不接看起來的 そう。
*   動詞＋そう：快要～（常配 今（いま）にも）、看樣子會～；否定 〜そうもありません。
*   接名詞 そうな、接動詞 そうに：おいしそうなパン、楽（たの）しそうに遊（あそ）ぶ。
*   一看就知道的事不用 そう：眼前的花直接說 きれいですね。
*   傳聞（聽說）：普通形＋そうだ；名詞、な形容詞加 だ：降（ふ）るそう、おいしいそう、元気（げんき）だそう、雨（あめ）だそう。
*   聽說的過去、否定放在前面：来（こ）なかったそうです，そうです 本身不變。
*   消息來源：〜によると（根據～）、〜の話（はなし）では（照～的說法）。
