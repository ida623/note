**從資料、學習方式、模型擬合到部署監控，建立完整的機器學習觀念地圖。**

### 讀完這課你會

*   分清楚人工智慧、機器學習與深度學習的包含關係
*   判斷一個問題該用迴歸、分類，還是非監督式方法

*【基礎架構】*

## AI 是大範圍，機器學習從資料裡學規律

人工智慧（Artificial Intelligence，AI）是讓系統執行感知、推理、學習、解題與決策等智慧任務的廣泛領域。機器學習（Machine Learning，ML）是 AI 的子集：不把每條規則寫死，而是讓演算法從資料中找出規律。

深度學習（Deep Learning，DL）又是機器學習的子集，用多層神經網路處理複雜模式；生成式 AI 則利用學到的分布去創造新內容。

```
AI
└─ 機器學習
   └─ 深度學習
      └─ 許多現代的生成式 AI 方法
```

一套 AI 系統通常包含資料層、演算法與框架層、模型層，以及把模型提供給使用者的應用層。任何一層出問題，結果都可能失去價值。

*【預測任務】*

## 迴歸問「多少」，分類問「哪一類」

| 任務 | 輸出 | 範例 |
| --- | --- | --- |
| 迴歸（Regression） | 連續數值 | 房價、溫度、銷售額 |
| 二元分類 | 兩個類別擇一 | 垃圾郵件或正常郵件 |
| 多類別分類 | 多個互斥類別擇一 | 照片是貓、狗還是鳥 |
| 多標籤分類 | 可以同時有多個標籤 | 一部電影同時屬於動作、科幻與冒險 |

記法：「回連、分離」——迴歸輸出連續數值，分類輸出離散類別。

*【資料型態】*

## 資料有沒有答案，決定可以怎麼學

標註資料（Labeled Data）同時有輸入特徵與正確答案；未標註資料（Unlabeled Data）只有輸入。結構化資料通常整齊排成欄與列，非結構化資料則包括自由文字、影像、音訊與影片。

| 學習方式 | 資料 | 典型任務 |
| --- | --- | --- |
| 監督式學習 | 有標籤 | 分類、迴歸 |
| 非監督式學習 | 無標籤 | 分群、降維、關聯規則、異常探索 |
| 半監督式學習 | 少量標註加大量未標註資料 | 先學一個初始模型，再產生並驗證推測出來的標籤 |
| 強化學習 | 環境給的獎勵 | 控制、遊戲與連續決策 |

非監督式分群像把沒有標籤的商品依相似度自動分堆；關聯規則學習則像從購物籃裡發現「買了甲商品的人常一起買乙商品」。

*【強化學習】*

## 代理人靠試誤改善策略

強化學習（Reinforcement Learning，RL）裡，代理人（Agent）觀察環境狀態（State），依策略（Policy）選擇動作（Action），再收到獎勵（Reward）。目標不是拿眼前最高分，而是讓一段時間內的累積獎勵最大。

```
觀察狀態 → 選擇動作 → 環境改變
     ↑                 ↓
     └── 更新策略 ← 收到獎勵
```

*【深度學習】*

## 多層神經網路會自己學出一層層的特徵

神經元會對輸入做加權總和，再經過激勵函數產生輸出。多層網路能逐層建立特徵：辨識照片時，前面的層可能先學到邊緣與顏色，後面的層再組成眼睛、臉部與完整物體。

傳統機器學習往往需要人工設計特徵；深度學習比較能自動學特徵，也擅長影像、語音與自然語言這類非結構化資料，但通常需要更多資料、更長的訓練時間與平行運算資源。

GPU 像一大隊同時開工的計算小隊，適合神經網路裡的矩陣與平行運算；CPU 則比較適合複雜的控制邏輯與一般用途的工作。實際怎麼選還是要看模型、資料量、延遲要求與成本。

*【資料準備】*

## 進去的是垃圾，出來的也是垃圾

模型只會從你給的資料學。如果資料錯誤、偏頗、過時，或根本代表不了真實使用情境，再複雜的模型也會得出不可靠的結果。

特徵工程（Feature Engineering）是用領域知識把原始資料轉成有意義的模型輸入，包括：

*   特徵提取：從出生日期算出年齡。
*   特徵選擇：留下真正對預測有幫助的欄位。
*   特徵轉換：縮放、標準化或重新編碼資料。

資料不足時，可以考慮遷移學習（Transfer Learning）、資料增強（Data Augmentation）、合成資料（Synthetic Data）或少樣本學習。這些方法能增加有效訊號，但不會自動修好錯誤的標籤或不具代表性的取樣。

*【評估】*

## 訓練集、驗證集與測試集各有各的工作

| 資料集 | 用途 | 注意事項 |
| --- | --- | --- |
| 訓練集 | 讓模型學習參數 | 模型會直接看過這批資料 |
| 驗證集 | 選模型與調整超參數 | 反覆使用也可能造成間接的過擬合 |
| 測試集 | 最後估計泛化能力 | 不該參與訓練與調參 |

實際的分割比例沒有唯一標準，要依資料量、時間順序、類別分布與業務情境設計，避免同一個對象或未來的資訊洩漏到不同資料集裡。

*【模型擬合】*

## 偏差與變異是一場平衡

| 狀態 | 表現 | 常見原因 |
| --- | --- | --- |
| 欠擬合（Underfitting） | 訓練與測試都差 | 模型太簡單、特徵不足，常伴隨高偏差 |
| 過擬合（Overfitting） | 訓練好、測試差 | 把訓練資料的雜訊也記住了，常伴隨高變異 |
| 平衡 | 訓練與測試都合理 | 模型抓到主要規律，而且能泛化 |

偏差（Bias）是系統性地偏離真實規律；變異（Variance）是模型對訓練資料的變動過度敏感。更複雜的模型可能降低偏差，卻讓變異上升，所以一定要用沒看過的資料來評估。

*【上線與循環】*

## 推論不是專案的終點

推論（Inference）是讓訓練好的模型對新資料產生預測。即時推論重視低延遲；批次推論則一次處理大量資料，適合可以晚一點完成的分析。

```
定義業務問題 → 蒐集與準備資料 → 特徵工程
→ 訓練與調參 → 評估 → 部署 → 推論
→ 監控效能與漂移 → 收集新資料 → 重新訓練
```

模型漂移（Model Drift）是指資料或真實世界的關係改變了，讓上線後的模型逐漸失準。所以監控、除錯、重新評估與更新資料，本來就是這個循環的一部分。

### 重點整理

*   先從業務問題決定任務類型與需要什麼資料，再選方法。
*   有標籤做監督式學習；沒標籤可以先探索資料的結構。
*   訓練集學參數、驗證集調超參數、測試集留到最後評估泛化。
*   訓練好但測試差是過擬合；兩邊都差通常是欠擬合。
*   上線之後還要持續監控漂移，必要時重新訓練。

## 隨堂測驗

**Q1. 公司要預測下個月的實際銷售金額，這屬於哪一種任務？**

- (A) 迴歸
- (B) 多類別分類
- (C) 非監督式分群
- (D) 關聯規則學習

<details><summary>看答案</summary>

**答案：(A)** 銷售金額是連續數值，輸出連續數值的預測任務就是迴歸。

</details>

**Q2. 一部電影可以同時被標成科幻、動作與冒險，這是哪一種分類？**

- (A) 多標籤分類
- (B) 多類別分類
- (C) 二元分類
- (D) 迴歸

<details><summary>看答案</summary>

**答案：(A)** 多類別分類是多個互斥類別擇一；可以同時貼好幾個標籤才叫多標籤。

</details>

**Q3. 手上只有客戶的交易特徵，沒有預先定義的客群標籤，想找出自然形成的群組，該用什麼方法？**

- (A) 非監督式分群
- (B) 監督式迴歸
- (C) 多標籤分類
- (D) 半監督式學習加人工標註

<details><summary>看答案</summary>

**答案：(A)** 沒有標籤而且目標是找資料內部的群組，就是典型的非監督式分群。

</details>

**Q4. 模型在訓練資料上表現極佳，但在測試資料明顯變差，最可能是什麼問題？**

- (A) 過擬合
- (B) 欠擬合
- (C) 資料尚未完成標準化
- (D) 測試集比訓練集大太多

<details><summary>看答案</summary>

**答案：(A)** 訓練好、沒看過的資料差，是模型記住訓練細節卻無法泛化的典型現象。

</details>

**Q5. 驗證集最主要的用途是什麼？**

- (A) 選擇模型與調整超參數
- (B) 直接更新模型的權重
- (C) 取代上線後的監控
- (D) 保存生產環境的預測結果

<details><summary>看答案</summary>

**答案：(A)** 訓練集負責學參數，驗證集負責選模型與調參，測試集留到最後做評估。

</details>

**Q6. 強化學習中的代理人怎麼改善自己的行為？**

- (A) 依狀態採取動作，再用收到的獎勵更新策略
- (B) 讀取已標註的答案做迴歸
- (C) 把所有輸入轉成向量後比對相似度
- (D) 由工程師事先把所有動作寫死

<details><summary>看答案</summary>

**答案：(A)** 強化學習靠代理人與環境互動，用獎勵訊號逐步調整策略。

</details>

**Q7. 為什麼深度學習常常使用 GPU？**

- (A) GPU 適合大量可平行的矩陣運算
- (B) GPU 能自動修正錯誤的標籤
- (C) GPU 能保證模型不會過擬合
- (D) GPU 會替專案決定業務目標

<details><summary>看答案</summary>

**答案：(A)** 神經網路訓練包含大量可以同時進行的矩陣運算，這正是 GPU 擅長的。

</details>

**Q8. 模型上線之後，資料分布逐漸改變導致準確度下降，這叫什麼？**

- (A) 模型漂移
- (B) 特徵提取
- (C) 欠擬合
- (D) 資料增強

<details><summary>看答案</summary>

**答案：(A)** 真實資料或輸入與結果的關係改變，會造成模型漂移，需要持續監控與重新訓練。

</details>
